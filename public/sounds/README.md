# 守護獣の鳴き声を実音源に差し替える

このフォルダに音声ファイルと `manifest.json` を置くと、ステージ1「守護獣の叫び」の
鳴き声が合成音から実音源に切り替わる。ファイルが無い場合は合成音のまま動く。

## 手順

1. 音声ファイルをこのフォルダに置く
2. 同じフォルダに `manifest.json` を作り、守護獣の番号とファイル名を対応させる

```json
{
  "0": "snake.webm",
  "1": "bat.webm",
  "2": "scorpion.webm",
  "3": "jackal.webm",
  "4": "falcon.webm",
  "5": "crocodile.webm"
}
```

番号と守護獣の対応は次のとおり。書かなかった番号は合成音のままになるので、
用意できたものから少しずつ差し替えられる。

| 番号 | 守護獣 | 実際の鳴き方 |
|------|--------|--------------|
| 0 | ヘビ（アペプ） | 威嚇のシャーという音。ほぼ雑音 |
| 1 | コウモリ（ネフト） | 耳に聞こえる社会音。短いキーッ |
| 2 | サソリ（セルケト） | 体をこすり合わせる乾いた摩擦音 |
| 3 | ジャッカル（アヌビス） | 犬科の遠吠え |
| 4 | ハヤブサ（ホルス） | 鋭い声を細かく連ねる |
| 5 | ワニ（ソベク） | 腹に響く低い咆哮 |

## 音源に求められる条件

- **長さは 0.5〜1.0 秒**。記憶ゲームなので、これより長いと出題のテンポが崩れる
- **無音の余白を前後に残さない**。押した瞬間に鳴らないと手応えが悪い
- **音量をそろえる**。1 つだけ大きいと、その守護獣だけ覚えやすくなってしまう
- 形式は webm(Opus) か mp3。ブラウザがそのまま再生できるもの

## 音量と長さをそろえる

`tools/prepare-sounds.mjs` に、切り出しと音量そろえを行うスクリプトがある。
ffmpeg が必要。

```sh
node tools/prepare-sounds.mjs 元音源フォルダ
```

## ライセンスについて

この場所に置く音源は、再配布が許されるライセンス（CC0 / パブリックドメイン等）の
ものに限ること。出典とライセンスを `credits.md` に必ず書き残すこと。
