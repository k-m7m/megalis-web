# 電脳迷宮メガリス Web版

2005年にタカラから発売された電子玩具「電脳迷宮メガリス」を、ブラウザで遊べる形に再現した**非公式のファンメイド作品**です。原作の権利は権利者に帰属します。本プロジェクトは個人の記憶と公開されている情報をもとに、有志が趣味で作成したものであり、タカラトミー社およびその関連会社とは一切関係ありません。

## 遊べる内容

ピラミッド型の迷宮に封じられた4つの試練を、順番に、あるいは好きな試練だけを選んで挑戦できます。

| # | 試練名 | ジャンル | 内容 |
|---|--------|----------|------|
| 1 | 守護獣の叫び | 音の記憶ゲーム | 6体の守護獣が順番に鳴く。光は出ないので、鳴き声だけを頼りに同じ順で石像に触れる。 |
| 2 | 大蛇の回廊 | パチンコ（ピンボール） | 玉を打ち出し、釘の間を抜けて光るポケットに落とす。 |
| 3 | 封印の扉 | 光の記憶ゲーム | 9枚の石板が順番に光る。位置と順番を覚えて同じ順になぞる。 |
| 4 | 呪われた谷 | イライラ棒 | 入り組んだ通路の壁に触れないよう、制限時間内にゴールまでポインタを運ぶ。 |

- **アドベンチャーモード**: 4つの試練を順番に突破し、伝説の秘宝を目指す。
- **フリーモード**: 好きな試練をひとつだけ選んで練習できる。
- 難易度は「やさしい」「ふつう」「むずかしい」の3段階。
- 効果音・BGMはすべて Web Audio API によるオリジナルの音声合成で、音源ファイルは一切使用していません。

## 技術構成

- [Vite](https://vitejs.dev/) + TypeScript（フレームワーク不使用のバニラ実装）
- 描画は DOM（記憶ゲーム系）と Canvas 2D（ピンボール・イライラ棒）
- 効果音は `AudioContext` のオシレータ・ノイズ合成のみで生成

## 開発

```sh
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド (dist/ に出力)
npm run preview   # ビルド結果をローカルでプレビュー
npm run typecheck # 型チェックのみ実行
```

## GitHub Pages への公開

このリポジトリには `.github/workflows/deploy-pages.yml` が入っており、`main` ブランチに push すると自動でビルドして GitHub Pages に公開される。初回のみリポジトリ側で以下の設定が必要。

1. GitHub の当リポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を `GitHub Actions` に設定する

設定後は `main` への push（または Actions タブから手動実行）で公開され、`https://k-m7m.github.io/megalis-web/` からアクセスできるようになる。
